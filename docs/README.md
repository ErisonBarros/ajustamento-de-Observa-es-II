# Documentação

Esta pasta contém toda a documentação teórica e prática da disciplina de Ajustamento de Observações II.

- **/teoria**: Materiais sobre os conceitos fundamentais, como a teoria dos erros, elipsoide de erros e intervalos de confiança.
- **/metodos**: Descrições detalhadas dos métodos de ajustamento, como o Método dos Mínimos Quadrados (MMQ) e o método combinado.
- **/exemplos**: Exemplos práticos de aplicação dos métodos de ajustamento em problemas reais.
